# SnapFrame

小さなアプリのウィンドウを1枚の「お盆」にまとめ、Windows のスナップでひとまとまりとして扱えるようにするツールです。

お盆をスナップすれば、載せたアプリ全部が一緒に動いてリサイズされます。

## 使い方

1. `snapframe.exe` を起動する
2. ツールバーの **「＋ ウィンドウを追加」** から、載せたいアプリを選ぶ
3. お盆ごと Win+←/→ などでスナップする

| 操作 | 動作 |
|---|---|
| ペイン間の境界をドラッグ | 分割比を変える |
| ペインのヘッダーをドラッグ → 別のペインで離す | 2つのペインを入れ替える |
| ペインをクリック | そのアプリにキーボードフォーカスを移す（アプリの中身でもヘッダーでも可） |
| ヘッダー右端の × | そのアプリだけをデスクトップに戻す |
| 「均等に整列」 | 分割比をリセットする |
| 「すべて解放」 | 全部をデスクトップに戻す |

ペインは追加した順に、なるべく正方形に近くなるよう「列 × 列内の段」に並びます。

フォーカスは通常のアプリと同じ感覚で動きます。載せたアプリのどこをクリックしてもそのアプリに入力が移り、他のウィンドウから戻ってきたときは最後に使っていたペインに戻ります。

アプリを元に戻すと、埋め込む前の枠・サイズ・位置がそのまま復元されます。お盆を閉じたときも同じです。

## ビルド

通常の PowerShell で動きます（VS の x64 Native Tools コンソールは不要でした。rustc が MSVC ツールチェーンを自力で見つけます）。

```bash
cargo run
```

```bash
cargo build --release
```

リリースビルドは LTO + `codegen-units=1` + `panic=abort` + `strip` で、153 KB 程度の単一 exe になります。

## 制限事項

- **ストアアプリ (UWP) は載せられません。** 電卓・設定などは Windows が `SetParent` を拒否します。選ぶと理由を説明するダイアログが出ます。管理者権限で動いているアプリも同様です。
- **お盆を強制終了させないでください。** Windows は親ウィンドウと一緒に子ウィンドウも破棄するため、タスクマネージャーから kill すると載せていたアプリのウィンドウごと消えます。× で普通に閉じれば全部きちんと戻ります（SnapFrame 自身が panic した場合も、道連れにする前に返却します）。
- 載せたアプリが自前で持っているタイトルバー相当の UI（Windows Terminal のタブ列など）はそのまま残ります。消せるのは OS が描く枠だけです。
- レイアウトは保存されません。起動するたびに空のお盆から始まります。
